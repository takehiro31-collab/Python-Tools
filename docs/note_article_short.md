# コードが書けない私が、AIに日本語で頼んで「ファイル自動整理ツール」を作ってもらった全手順

コードが書けなくても、AIに日本語で頼めば、ファイルを自動で整理する道具は作れます。
プログラミング初心者の私が、実際にやった手順をまとめました。

## ダウンロードフォルダ、散らかっていませんか

PDF、写真、Excel、覚えのない zip。
開くたびに「そのうち整理しよう」と閉じてしまう。
私も同じでした。

## やったのは、日本語で相談しただけ

きっかけは「noteで記事を売りたい」でした。
AIに相談して、3つのことが分かりました。

- noteには公式の連携の仕組みがない。投稿の自動化は壊れやすく、おすすめできない
- 売れやすいのは、自分がやったことを再現できる手順にした記事
- 初心者であることは強み。つまずいた所は、上級者には書けない

そこで、身近なファイル整理をAIと自動化することにしました。

## できたツール

1行打つだけで、ファイルが種類ごとのフォルダに分かれます。

【画像：整理前のフォルダ】
【画像：整理後のフォルダ】

| 振り分け先 | 入るファイルの例 |
|---|---|
| 画像 | .jpg / .png / .heic など |
| 文書 | .pdf / .docx / .txt など |
| 表計算 | .xlsx / .csv など |
| スライド | .pptx など |
| 動画・音楽 | .mp4 / .mp3 など |
| 圧縮ファイル | .zip など |
| インストーラー | .exe / .dmg など |
| その他 | 上のどれにも当てはまらないもの |

大事なファイルが消えないよう、安全装置を3つ付けました。

- **まず確認だけ。** 移動先の一覧を見せるだけで、ファイルは動かさない
- **上書きしない。** 同じ名前があれば「名前 (2).jpg」と番号を付ける
- **フォルダや隠しファイルには触らない。**

## AIへの頼み方：送ったのは4つだけ

> ① noteと連携はできますか
> ② note記事販売を行いたいのですが、内容はなにがいいでしょうか
> ③ 初心者です
> ④ その内容とターゲットでいこう

AIは、こう話を進めてくれました。

1. ①で、できること・できないことを表にした
2. ②で、売れやすい記事の条件と案を出した
3. ③で、初心者目線に絞った
4. ④で、ツールと使い方の説明を作った

コツは3つです。

- **やりたいことを、そのまま書く。**
- **「初心者です」と添える。** 説明がやさしくなります
- **一度で決めない。** 会話を重ねると、やることが絞れます

最初の一言は、これで十分です。

> 私はプログラミング初心者です。パソコンの【困っている作業】を自動化したいです。何ができますか？

## パソコンで動かす手順

黒い画面（ターミナル）に打つのは1行だけです。
フォルダの場所は、ドラッグ＆ドロップで入れます。

### ステップ1：Python を入れる（最初の1回だけ）

https://www.python.org/downloads/ からインストールします。
**Windows は「Add python.exe to PATH」に必ずチェック。** 忘れたら、入れ直せば直ります。

### ステップ2：ツールを置く

付録のコードを `organize.py` という名前で、デスクトップに保存します。

### ステップ3：確認する（ファイルはまだ動きません）

1. 黒い画面を開く（Windows：「cmd」で検索／Mac：⌘＋スペースで「ターミナル」と検索）
2. `python ` と打つ（Mac は `python3 `。最後に半角スペース）
3. `organize.py` を画面にドラッグ＆ドロップ
4. 半角スペースを1つ打つ
5. 整理したいフォルダをドラッグ＆ドロップ
6. Enter を押す

移動先の一覧が出ます。まだ何も動いていません。

### ステップ4：整理する

↑キーで前の行を出し、最後に ` --run` を足して Enter。
「〇個のファイルを整理しました。」と出たら完了です。

### うまくいかないとき

| 表示 | 直し方 |
|---|---|
| 「python が見つかりません」（Windows） | 「Add python.exe to PATH」にチェックして入れ直す。または `py` と打つ |
| 「command not found: python」（Mac） | `python3` と打つ |
| 「フォルダが見つかりません」 | フォルダをドラッグ＆ドロップし直す |
| 「整理するファイルはありませんでした」 | 中にファイルがない（フォルダは対象外） |

## 自分用に改造する

コード上部の対応表に1行足すと、振り分けの種類を増やせます。

```python
"デザイン": [".psd", ".ai", ".fig"],
```

書き方が分からなければ、AIにこう頼めば教えてくれます。

> この organize.py で、【拡張子】のファイルを「【フォルダ名】」フォルダに入れるようにしたいです。どこに何を書けばいいですか？
