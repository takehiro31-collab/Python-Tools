私もまったく同じ状態でした。プログラミングは初心者です。

## 私がやったのは「日本語で相談しただけ」

最初から「ツールを作ろう」と思っていたわけではありません。
きっかけは、noteで記事を売ってみたいと思ったことでした。

AIに相談して分かったことは3つです。

- **noteには公式の連携の仕組み（API）がない。** 記事の一覧を読み取ることはできても、投稿の自動化は壊れやすく、おすすめできないと言われました
- **売れやすいのは「自分が実際にやったこと」を、再現できる手順にまとめた記事。** ネットで調べれば分かる一般論は売れにくいそうです
- **初心者であることは弱みではなく強み。** 「どこでつまずいたか」は、上級者には書けないからです

そこで「初心者の私が、AIと一緒に身近な作業を自動化してみる」ことにしました。
題材に選んだのが、散らかったファイルの整理です。

## できあがったツールはこれ

コマンドを1行打つだけで、フォルダの中のファイルが種類ごとに振り分けられます。

【画像：整理前のフォルダ】
【画像：整理後のフォルダ】

| 振り分け先 | 入るファイルの例 |
|---|---|
| 画像 | .jpg / .png / .heic など |
| 文書 | .pdf / .docx / .txt など |
| 表計算 | .xlsx / .csv など |
| スライド | .pptx など |
| 動画・音楽 | .mp4 / .mp3 など |
| 圧縮ファイル | .zip など |
| インストーラー | .exe / .dmg など |
| その他 | 上のどれにも当てはまらないもの |

初心者の私が一番こわかったのは「大事なファイルが消えたらどうしよう」でした。なので、次の3つの安全装置を付けてもらっています。

- **いきなり動かさない。** まず「どこに移動するか」の一覧を見せるだけの確認モードで動きます
- **上書きしない。** 同じ名前のファイルがあれば「名前 (2).jpg」のように番号を付けます
- **フォルダや隠しファイルには触らない。**

## 自分のパソコンで動かす手順

「黒い画面」（ターミナル）を使いますが、打つのは1行だけです。
**フォルダの場所は、手で打たずにドラッグ＆ドロップで入れられます。** ここが一番のポイントです。

### ステップ1：Python を入れる（最初の1回だけ）

1. https://www.python.org/downloads/ を開き、黄色いボタンからダウンロードしてインストールします
2. **Windows の人は、インストール画面の一番下にある「Add python.exe to PATH」に必ずチェックを入れてください。**
   ここを忘れると、あとで「python が見つかりません」と表示されます。忘れた場合は、もう一度インストールし直せば直ります

### ステップ2：ツールを置く

末尾の付録にあるコードを `organize.py` という名前で保存し、デスクトップに置きます。

### ステップ3：確認モードで動かす（ファイルはまだ動きません）

1. ターミナルを開きます
   - Windows：スタートメニューで「cmd」と検索して「コマンドプロンプト」を開く
   - Mac：Spotlight（⌘＋スペース）で「ターミナル」と検索して開く
2. `python ` と打ちます（最後に半角スペースを1つ）。**Mac の人は `python3 ` です**
3. デスクトップの `organize.py` を、ターミナルの画面にドラッグ＆ドロップします
4. 半角スペースを1つ打ちます
5. 整理したいフォルダ（ダウンロードなど）を、同じようにドラッグ＆ドロップします
6. Enter キーを押します

「どのファイルがどのフォルダに入るか」の一覧が表示されます。この時点では、何も動いていません。

### ステップ4：本当に整理する

一覧を見て問題がなければ、同じ行の最後に ` --run` を付けて実行します。
（キーボードの ↑ を押すと、さっき打った行がもう一度出てくるので、最後に ` --run` を足して Enter を押すだけです）

「〇個のファイルを整理しました。」と表示されたら完了です。

### うまくいかないとき

| 表示されたこと | 直し方 |
|---|---|
| 「python が見つかりません」（Windows） | 「Add python.exe to PATH」にチェックを入れて、Python をインストールし直す。または `python` の代わりに `py` と打つ |
| 「command not found: python」（Mac） | `python3` と打つ |
| 「フォルダが見つかりません」 | フォルダをドラッグ＆ドロップで入れ直す |
| 「整理するファイルはありませんでした」 | フォルダの中にファイルがない状態です（フォルダは対象外です） |

## 自分用に改造する

コードの上のほうに、次のような「対応表」があります。

```python
"画像": [".jpg", ".jpeg", ".png", ".gif", ".bmp", ".webp", ".heic", ".svg"],
```

ここに1行足すだけで、振り分けの種類を増やせます。たとえば、デザインのファイルを分けたいなら次の1行を足します。

```python
"デザイン": [".psd", ".ai", ".fig"],
```

書き方が分からなくても大丈夫です。AIにこう頼めば、直した行を教えてくれます。

## 付録：organize.py（コード全文）

```python
"""フォルダの中のファイルを、種類ごとのフォルダに自動で振り分けるツール。

使い方:
    python organize.py フォルダの場所            # まずは確認だけ（ファイルは動かさない）
    python organize.py フォルダの場所 --run      # 実際に振り分ける
"""

import argparse
import sys
from pathlib import Path

# 拡張子（ファイル名の最後の .jpg など）と、振り分け先フォルダ名の対応表。
# ここに行を足せば、好きな種類を増やせます。
CATEGORIES = {
    "画像": [".jpg", ".jpeg", ".png", ".gif", ".bmp", ".webp", ".heic", ".svg"],
    "文書": [".pdf", ".doc", ".docx", ".txt", ".md", ".rtf", ".odt"],
    "表計算": [".xls", ".xlsx", ".csv", ".ods"],
    "スライド": [".ppt", ".pptx", ".key", ".odp"],
    "動画": [".mp4", ".mov", ".avi", ".mkv", ".wmv", ".webm"],
    "音楽": [".mp3", ".wav", ".m4a", ".aac", ".flac"],
    "圧縮ファイル": [".zip", ".rar", ".7z", ".tar", ".gz"],
    "インストーラー": [".exe", ".msi", ".dmg", ".pkg"],
}
OTHER = "その他"


def category_for(path):
    """ファイルの拡張子から、振り分け先のフォルダ名を決める。"""
    ext = path.suffix.lower()
    for name, extensions in CATEGORIES.items():
        if ext in extensions:
            return name
    return OTHER


def unique_destination(dest):
    """同じ名前のファイルがすでにあるときは「名前 (2).jpg」のように番号を付ける。"""
    if not dest.exists():
        return dest
    n = 2
    while True:
        candidate = dest.with_name(f"{dest.stem} ({n}){dest.suffix}")
        if not candidate.exists():
            return candidate
        n += 1


def plan_moves(folder):
    """どのファイルをどこへ動かすかの一覧を作る（まだ動かさない）。"""
    moves = []
    for path in sorted(folder.iterdir()):
        # フォルダや、隠しファイル（.DS_Store など）は触らない
        if not path.is_file() or path.name.startswith("."):
            continue
        moves.append((path, folder / category_for(path) / path.name))
    return moves


def organize(folder, run=False):
    """振り分けを実行する。run=False のときは予定を表示するだけ。"""
    moves = plan_moves(folder)
    if not moves:
        print("整理するファイルはありませんでした。")
        return 0

    for src, dest in moves:
        if run:
            dest.parent.mkdir(exist_ok=True)
            dest = unique_destination(dest)
            src.rename(dest)
        print(f"{src.name}  →  {dest.parent.name}/{dest.name}")

    if run:
        print(f"\n{len(moves)} 個のファイルを整理しました。")
    else:
        print(f"\n{len(moves)} 個のファイルが上のように整理されます。")
        print("実際に動かすときは、最後に --run を付けて実行してください。")
    return len(moves)


def main():
    parser = argparse.ArgumentParser(description="ファイルを種類ごとのフォルダに振り分けます。")
    parser.add_argument("folder", help="整理したいフォルダの場所")
    parser.add_argument("--run", action="store_true", help="確認ではなく、実際にファイルを動かす")
    args = parser.parse_args()

    folder = Path(args.folder).expanduser()
    if not folder.is_dir():
        print(f"フォルダが見つかりません: {folder}")
        sys.exit(1)

    organize(folder, run=args.run)


if __name__ == "__main__":
    main()
```
