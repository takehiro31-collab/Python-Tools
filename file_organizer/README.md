# ファイル自動整理ツール

フォルダの中のファイルを「画像」「文書」「動画」などの種類ごとに、自動でフォルダ分けします。
Python だけで動き、追加のインストールは不要です。

## 準備

1. Python をインストールする（https://www.python.org/downloads/ ）
   - Windows の場合、インストール画面の「Add python.exe to PATH」に必ずチェックを入れてください
2. `organize.py` をダウンロードして、わかりやすい場所（例: デスクトップ）に置く

## 使い方

ターミナル（Windows は「コマンドプロンプト」、Mac は「ターミナル」）を開いて、次のように入力します。

### ① まずは確認だけ（ファイルは動きません）

```
python organize.py ~/Downloads
```

「どのファイルがどのフォルダに入るか」が一覧で表示されます。

### ② 問題なければ、実際に整理する

```
python organize.py ~/Downloads --run
```

> Mac で `python` が見つからないと言われたら `python3` に置き換えてください。
> Windows でフォルダを指定するときは `C:\Users\あなたの名前\Downloads` のように書きます。

## 安心ポイント

- `--run` を付けない限り、ファイルは一切動きません
- 同じ名前のファイルがあっても上書きせず、「名前 (2).jpg」のように番号を付けます
- フォルダや隠しファイルには触りません

## 自分用に改造するには

`organize.py` の上のほうにある `CATEGORIES` に行を足すと、振り分けの種類を増やせます。

```python
"デザイン": [".psd", ".ai", ".fig"],
```
